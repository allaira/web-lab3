Про автора

Спеціалізуюся на розробці 3D-ігор, проєктуванні інтерактивних механік та програмуванні на C# та C++. Працюю з рушієм Unity: створюю логіку взаємодії персонажів із навколишнім середовищем, налаштовують фізику об'єктів та оптимізую ресурси гри. Поєдную технічний підхід до написання коду з розумінням ігрового дизайну та атмосфери.

Основні роботи

3D Environment Design

Моделювання приміщення, налаштування модульної геометрії стін, джерел світла та запікання тіней.

Low-Poly Game Assets

Створення оптимізованих 3D-моделей предметів, налаштування розгортки (UV) та стилізованих текстур для гри.

Game UI & Inventory System

Проєктування інтерфейсу користувача: сітка інвентарю, слоти екіпірування та меню взаємодії з предметами.

Ігрові прототипи та оптимізація

Створюю інтерактивні прототипи ігрових механік на замовлення, налаштовую фізику та UI-інтерфейси для інді-ігор, проводжу рефакторинг та оптимізацію C# скриптів.
